THE 3 SOLUTIONS
================================================================================

┌─ OPTION 1: Smart Fabrication Guard (Default) ──────────────────────────┐
│                                                                           │
│  What: Automatic intelligent validation                                  │
│  When: Works by default on every save_tailored_cv() call                │
│  How:  1. Extract all protected numbers/metrics                         │
│        2. Check if all base numbers present in proposed CV              │
│        3. Calculate string similarity (>70% approved)                   │
│        4. APPROVE if: numbers preserved AND similarity >70%             │
│                                                                           │
│  Usage: save_tailored_cv(company, content)                              │
│  Result: ✅ Auto-approved OR ⚠️ requires_approval                       │
│                                                                           │
│  Best for: Fast workflow, you trust the algorithm                       │
└───────────────────────────────────────────────────────────────────────────┘

┌─ OPTION 2: review_cv_changes() Tool (New) ─────────────────────────────┐
│                                                                           │
│  What: Dedicated pre-save analysis and review tool                      │
│  When: Call BEFORE save_tailored_cv() to see details                    │
│  How:  1. Compares proposed vs base CV                                  │
│        2. Identifies exact matches & rewording                          │
│        3. Calculates similarity per protected line                      │
│        4. Returns: status, scores, recommendations                      │
│                                                                           │
│  Usage: analysis = review_cv_changes(company, content)                  │
│  Result: {"status": "approved|needs_review|rejected",                  │
│           "protected_lines_analysis": {...},                            │
│           "similarity_scores": {...},                                   │
│           "recommendations": [...]}                                     │
│                                                                           │
│  Best for: Detailed visibility, training, compliance trail              │
└───────────────────────────────────────────────────────────────────────────┘

┌─ OPTION 3: allow_rewording Flag (New Parameter) ──────────────────────┐
│                                                                           │
│  What: Manual approval flag for smart guard                             │
│  When: Add to save_tailored_cv() when ready to approve                  │
│  How:  1. Smart guard still runs validation                             │
│        2. If issues found, returns analysis (no error)                  │
│        3. You decide to save or fix                                     │
│                                                                           │
│  Usage: save_tailored_cv(company, content, allow_rewording=true)        │
│  Result: ✅ Saved OR ⚠️ requires_approval (with analysis)              │
│                                                                           │
│  Best for: Manual control, explicit approval trail                      │
└───────────────────────────────────────────────────────────────────────────┘

================================================================================
SMART GUARD ALGORITHM
================================================================================

Input: base_cv, proposed_cv

Step 1: Extract Protected Lines
  ├─ Lines with numbers: "Led 5 engineers", "$2M ARR", "95% satisfaction"
  └─ Lines with keywords: "ARR target", "quota exceeded"

Step 2: Check Number Preservation
  ├─ Base numbers: [5, 2000000, 95]
  └─ Proposed numbers: [5, 2000000, 95]
     Result: ✅ All numbers present

Step 3: Calculate Similarity (per line)
  ├─ "Led 5 engineers" vs "Managed 5-person team" → 95% ✅
  ├─ "Delivered $2M ARR" vs "Brought in $2M annual revenue" → 82% ⚠️
  └─ "Achieved 95%" vs "Achieved strong satisfaction" → 45% ❌

Step 4: Decision Logic
  ├─ All numbers present? ✅ YES
  ├─ All similarities >70%? ⚠️ 2/3 YES (one is 82%, one is 45%)
  └─ RESULT: ⚠️ REQUIRES_APPROVAL (risky rewording detected)

Step 5: Return Analysis
  ├─ exact_matches: []
  ├─ reworded_acceptable: [{"line": "Led 5", "similarity": 0.95}]
  ├─ reworded_risky: [{"line": "Delivered $2M", "similarity": 0.82}]
  ├─ altered_unacceptable: [{"line": "Achieved 95%", "similarity": 0.45}]
  └─ recommendation: "Fix the altered line or approve with allow_rewording=true"

  Result: ❌ REJECTED
  Reason: Too different, needs manual fix or approval
